# 🧮 Build a Desktop Application – Java Calculator

## 📌 Project Overview

This project is a simple **Java Calculator Desktop Application** that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. It demonstrates the use of Java programming concepts, user input handling, conditional statements, and arithmetic operations.

The application is designed as a beginner-friendly project to strengthen fundamental Java programming skills.

## 🚀 Getting Started

### Prerequisites

* Java Development Kit (JDK 8 or above)
* Command Prompt / Terminal

### Installation

1. Clone or download this repository.
2. Navigate to the project directory.
3. Compile the Java program:

```bash
javac CalculatorApp.java
```

4. Run the application:

```bash
java CalculatorApp
```

---

## 📖 How to Use

1. Run the application.
2. Enter the first number.
3. Enter the second number.
4. Enter an operator (`+`, `-`, `*`, `/`).
5. View the calculated result.
